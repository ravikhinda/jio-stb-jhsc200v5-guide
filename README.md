# Jio STB JHSC200v5 Guide

This folder contains the static HTML guide for publishing with GitHub Pages.

## Publish with GitHub Pages

1. Sign in to GitHub and create a **new public repository** (for example, `jio-stb-jhsc200v5-guide`).
2. Upload `index.html` from this folder to the repository's root.
3. Open the repository's **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for the Pages deployment to finish. GitHub will show the public website URL in Settings → Pages.

The site is a static HTML page; no build tools or server are required.
