How I Jailbroke My Jio STB

Model: JHSC200v5

Disclaimer: I am not a developer or an Android expert. I am just a regular Jio STB user sharing my personal experience and the method that worked for me. I created this guide to help other users who may be trying to set up their Jio STB. Everything shared here is based on my own experience, not professional expertise. The results may vary depending on the STB model and software version. Please follow the steps carefully and proceed at your own risk.

Step-1: Install Prerequisites on Your PC

First, download the ZIP file of the repository from this link:

https://github.com/ilikechocopies/sideload-jiostb

Extract it to your PC. Then install the following required tools:

  • Docker Desktop: https://docs.docker.com/desktop/setup/install/windows-install/
  • Python 3: https://www.python.org/downloads/
  • Technitium DNS: https://technitium.com/dns/
  • Git for Windows: https://gitforwindows.org/

Step-2: Network and Cable Setup

Next, I prepared my setup for network pairing:

  • Connected the Jio STB to my router using an Ethernet cable.
  • Connected my laptop to the Wi-Fi of the same router so that both devices were on the same network.

Step-3: Find Your Laptop's IP Address

Open CMD on your laptop and enter the following command:

ipconfig

Find the IPv4 Address (for example, 192.168.x.x) and note it down.

We will use this IP address as the DNS server in the upcoming steps.

Step-4: Configure DNS on the Jio STB

For this, I accessed the hidden Android settings on my STB:

  1. Download the My Music app from the Jio Store.
  2. Insert an empty USB flash drive into the STB.
  3. Open the My Music app.
  4. Follow this path: Settings > Safely eject the USB > Internal shared storage > Apps > Settings > Open > Network and Internet.
  5. Here, you will find the Ethernet option. Change its configuration from DHCP to Static.
Note: As soon as you switch to Static, you will need to enter all the values manually. Therefore, I first noted down the STB's default IP address and Gateway. I entered the same IP address and Gateway again. The only change I made was to replace DNS 1 with the laptop's IPv4 address that I noted in Step 3. Finally, save the settings.

Step-5: Turn Off Windows Defender Firewall and Isolate the Network (Important)

To connect the Jio STB to our laptop instead of the original server, we need to isolate our local network and turn off the firewall. Without these two steps, the further process will fail.

1. Disconnect the Internet from Your Router

Disconnect the main Internet (WAN/Fiber) cable plugged into the back of your Wi-Fi router so that the router stops receiving an Internet connection.

Note: Your laptop and STB must remain connected to the same router. Only the Internet connection should be disabled so that both devices can communicate with each other over the local network.

2. Turn Off Windows Defender Firewall

  1. On your laptop, press Win + R.
  2. Type firewall.cpl and press Enter.
  3. From the left-side menu, click Turn Windows Defender Firewall on or off.
  4. Select Turn off Windows Defender Firewall (not recommended) for both Private and Public networks.
  5. Click OK.

(We will turn it back on once the process is complete.)

Step-6: Run Docker

Now, open Docker Desktop from the Start Menu.

Wait for a while until the Docker engine starts and its status changes to Running.

Step-7: Set Up Technitium DNS

Now, we will configure the DNS server so that the STB's traffic can be redirected.

  1. Open your laptop's browser and visit http://localhost:5380. This is the Technitium console.
  2. Go to Zones in the menu and click Add Zone.
  3. Enter the following details:
    • Zone Name: jio.com
    • Zone Type: Primary Zone
  4. Now, click on jio.com from the list and press the Add Record button.
  5. Enter the following details:
    • Name: acs.oss
    • Type: A
    • IP Address: Enter the same laptop IPv4 address that you noted in Step 3.
  6. Save the record.

Finally, check once that the jio.com zone is showing as Enabled.

Step-8: Deploy TLS Containers (Temporary Internet Required)

Now, we will deploy the TLS containers. When you run this command, Docker will download some required files from the Internet. Therefore, we need to temporarily enable the Internet connection.

1. Turn the Internet ON

Reconnect the Internet cable (WAN) that you disconnected in Step 5 so that your laptop gets an Internet connection again.

2. Open the TLS Folder

  1. Open File Explorer on your laptop.
  2. Navigate to the sideload-jiostb/tls folder.
  3. Click on the Address Bar at the top of the folder window (where the folder path is displayed).
  4. Type cmd and press Enter.

This will open Command Prompt directly inside that folder.

3. Run the Docker Command

In the Command Prompt window, type the following command and press Enter:

docker compose up -d

After that, install the required Python cryptography package by running this command:

pip3 install cryptography

4. Turn the Internet OFF Again (Important)

As soon as the command finishes and the files have been downloaded and the containers have been set up, immediately disconnect the Internet cable from your router again.

The remaining exploit process will work locally without an Internet connection.

Step-9: Start the Proxy Listener

Since our box belongs to the JHSC200 series (JioOS 2.0), it performs strict CA certificate validation checks and rejects the default certificate.

Therefore, we need to run a special script.

  1. Go back to the main sideload-jiostb folder on your laptop.
  2. Open Git Bash inside that folder.
  3. Enter the following certificate-related command in Git Bash and press Enter:
./jhs/run_acs.sh
Note: This script will automatically generate an eMudhra certificate and launch the proxy. Keep this terminal window open. Do not close it!

Step-10: Git Bash and Health Check (Testing the Setup)

Before doing anything on the TV, we will check whether the laptop setup is working correctly.

  1. Go back to the main sideload-jiostb folder on your laptop.
  2. Right-click on an empty space inside the folder.
  3. Click Show more options.
  4. Select Open Git Bash here.

(This step is optional but highly recommended.)

In Git Bash, enter the following commands one by one:

python doctor.py --quick
python doctor.py --simulate
Note: The --simulate command sends a fake request to check whether your proxy and GenieACS are working properly and whether the entire setup is functioning correctly.

Step-11: Cold Power-Cycle the STB

Now, we need to restart the STB so that it can connect to our setup.

  1. Unplug the main power plug of your Jio STB directly from the wall socket.
  2. Do not turn it off using the TV remote.
  3. Wait for 5 to 6 seconds after unplugging it.
  4. Plug it back in and allow the STB to boot completely.

Step-12: Execute Stage 1

Before proceeding, make sure that Docker, Technitium DNS, and the proxy listener (which we left running in Step 9) are all active.

1. Check Connected Devices

First, enter the following command in Git Bash and press Enter:

./stage1.sh --list-devices

After running this command, two options will appear in the list:

  • 1: Test Device
  • 2: Jio STB

2. Run Only the Required Payload

Now, execute the following command:

./stage1.sh --tasks-only

When the command prompts you to select a model, type 2 and press Enter to select the Jio STB.

Step-13: Second Cold Power-Cycle and ADB Connection (My Real Experience)

The Jio STB can take hours to connect automatically in the background. Therefore, to connect ADB immediately, we need to force-restart the STB one more time (for the second time).

1. Second Cold Power-Cycle

Unplug the STB's main power plug from the wall socket. Wait for 5–6 seconds, then plug it back in and let it boot completely.

(Remember, we are repeating this step for the second time. Do not turn it off using the TV remote.)

2. First ADB Command

As soon as the box turns on, without waiting, manually enter this command in Git Bash and press Enter:

adb connect <YOUR_STB_IP>:5555

(Replace it with your actual STB IP address.)

3. Allow the TV Pop-up

As soon as you enter the command, an "Allow USB Debugging?" pop-up will immediately appear on your TV screen.

Using your remote:

  • Tick Always allow from this computer.
  • Select OK.

If your PC displays failed to authenticate, do not panic. This is normal.

4. Second ADB Command (Important)

After selecting OK on the TV, run the exact same command again in Git Bash:

adb connect <YOUR_STB_IP>:5555

Now, it should display:

connected to IP:5555

5. Verify the Connection

Once completed, enter the following command in Git Bash:

adb devices

If your device appears in the list with the status device, it means your setup has been successfully completed!

Important Note: It is not necessary that the ADB connection will work on the very first attempt. If you get an error after entering the command or the TV pop-up does not appear, do not panic. You may need to perform a cold start (unplugging and reconnecting the power plug) 2–3 times until the connection becomes successful.

Step-14: Edit and Run the Post-Setup Script

To complete the post-setup process, we need to run a script. However, before running it, we must enter the actual IP address of our Jio STB because the script already contains a default IP address.

  1. Go back to the main sideload-jiostb folder on your laptop.
  2. Open the folder named jhs.
  3. Find the script file named jhs_stage1.sh.
  4. Right-click on it and open it with Notepad.
  5. Inside the file, you will find STB_IP.
  6. Replace the default IP address with the actual IP address of your Jio STB.
  7. Save the file using Ctrl + S and close Notepad.

Now, return to your Git Bash terminal (where the main folder was opened) and enter the following command:

./jhs/jhs_stage1.sh --post-setup

After running this command, your post-setup will be completed successfully, and the entire jailbreak process will be finished!

Step-15: Teardown and Restore Everything to Normal

Once the ADB connection is established and your jailbreak setup is complete, it is important to restore everything to its normal state.

1. Stop the Proxy Script

Go to the terminal window where run_acs.sh is running.

Click inside that window and press:

Ctrl + C

This will stop the running proxy script.

2. Stop Docker Containers

Open Git Bash and run the following command to stop the Docker containers:

docker compose down

3. Turn the Router Internet Back ON

Reconnect the main Internet cable that you disconnected from your router in Step 10.

4. Turn Windows Defender Firewall Back ON

  1. Press Win + R.
  2. Type firewall.cpl.
  3. Open Turn Windows Defender Firewall on or off.
  4. Turn Windows Defender Firewall back ON.

5. Verification

Your STB and laptop should now have their Internet connections working again.

Step-16: Install Apps (APK) Through ADB

Since the built-in package installer UI is disabled on the Jio STB, you will need to install Android TV APKs directly from your PC.

1. Connect ADB

If your PC is not already connected to the STB, run the following command in Git Bash:

adb connect <STB_IP_ADDRESS>:5555

2. Install an APK

To sideload (install) any Android TV app from your PC, run the following command:

adb install "C:\path\to\your\app.apk"

(Replace the path inside the quotation marks with the actual location/path of your APK file.)

Once the installation is complete, the app will immediately appear inside the Monet Launcher of your STB!

End of guide.
